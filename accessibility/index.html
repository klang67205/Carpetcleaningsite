Accessibility

Last updated October 19, 2026

We want everyone to be able to see prices, ask questions and book a cleaning on this website. We test it against the Web Content Accessibility Guidelines (WCAG) 2.2, level AA.

What we test

  • Every page with an automated WCAG 2.2 AA checker at phone and desktop widths.
  • Keyboard use: every link and button can be reached and shows a visible focus outline.
  • Text size, tap targets of at least 24 pixels, color contrast, and reduced motion.

Known limits

  • Online booking runs on Housecall Pro’s scheduler, which we don’t control. If any step is hard to use, text us and we’ll book it with you.
  • Facebook Messenger follows Meta’s own accessibility features.

Get help or report a barrier

Text (316) 232-8111 with the page or task where you got stuck. We’ll help you finish it and fix the page.
