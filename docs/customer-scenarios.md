# Customer concierge scenarios

The booking guide now handles these 25 customer paths using verified business information: standard-price questions, package coverage, extra rooms, pet treatment, drying, furniture, preparation, service area, on-base housing, hours, booking availability, cancellation, rescheduling, late arrival, access instructions, commercial or unusual work, upholstery/tile/hard-floor questions, stain expectations, mold/sewage/flooding, payment, invoices, complaints, weather, and chemical-sensitivity concerns.

For a new booking, it sends the customer directly to the live Housecall Pro booking page. For an existing appointment, it sends the customer to the manage-appointment link in that appointment's Housecall Pro confirmation. Housecall Pro Basic does not expose a public API or webhook that allows a separate website assistant to identify, reschedule, cancel, or edit an existing job. The confirmation link is the available self-service boundary.
